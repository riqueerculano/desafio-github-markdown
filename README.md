
# 🚀 Desafio GitHub Markdown

## 👨‍💻 Sobre o projeto

Este projeto tem como objetivo colocar em prática os conhecimentos de Git, GitHub e Markdown, explorando conceitos de controle de versão, colaboração e documentação de projetos.

## 🎯 Objetivos

- [x] Criar repositório
- [x] Abrir GitHub.dev
- [x] Desenvolver README
- [ ] Realizar commits
- [ ] Criar Issues
- [ ] Criar Pull Requests
- [ ] Praticar colaboração

## 🛠️ Tecnologias utilizadas

- Git
- GitHub
- Markdown
- Visual Studio Code

## 📌 Como utilizar

Este repositório foi criado para praticar Git,
GitHub, Markdown e colaboração em projetos.

Explore os arquivos e acompanhe a evolução
do desafio por meio das Issues e Pull Requests.
